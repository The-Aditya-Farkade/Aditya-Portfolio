## ✨ Features

* **Hero & About:** Brief professional summary with quick links to download resume and explore projects.
* **Academic Journey:** Timeline of educational background from Secondary Schooling through MCA.
* **Work Experience:** Detailed history of roles including NOMC Executive responsibilities and Full-Stack Web Development internships.
* **Featured Projects:** Showcase of key technical projects complete with tech stack tags, live demo links, and GitHub repositories.
* **Animated Skills & Toolkit:** Dynamic progress bars and visual badges for languages, databases, visualization platforms, and security tools.
* **Interactive AI Assistant:** Embedded chat assistant for quick query resolution about skills, background, and contact details.
* **Contact Form & Quick Details:** Integrated contact options for collaboration and freelance inquiries.

---

## 🛠️ Tech Stack & Tools

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Styling & UI:** Glassmorphism, CSS Animations, Responsive Grid/Flexbox
* **Data & Analytics:** Power BI, SQL, MySQL, MongoDB, Tableau
* **Developer Tools:** VS Code, Git/GitHub, Postman, AWS, Kali Linux

## 📂 Featured Projects
